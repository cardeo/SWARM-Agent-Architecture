# Changelog

## v0.1 - 2026-09

First public versioned statement of SWARM Agent Architecture.

This release establishes:

- Six-layer architecture
- SWARM recursive protocol
- Human-directed governance model
- Governed Adaptation workflow
- Runtime-mode distinction
- Entity Surface pattern
- Private Grant Scout reference implementation lineage

The generic Agent Template, reusable runtime, SWARM Design System, and public
reference agents remain future work. They are intentionally deferred until
additional implementations provide evidence for what should become reusable.
